## 2. Апаратна база та модифікації (Stage 1 — Завершено та протестовано)
- **Мікроконтролер:** `ESP32-S3-DevKitC-1` (PlatformIO + Arduino Framework, `platform = espressif32 @ 6.7.0`).
- **Штатна плата лампи:** `X8-6R-21` (5V / 2A).
  - Роз'єм micro-USB замінено на **USB Type-C**.
  - Штатний 8-ногий контролер `U1` (SOP-8) випаяно.
  - Залишено штатні N-канальні MOSFET **AO3400A** (`A09T`): `Q1` (холодний білий) та `Q2` (теплий жовтий), затвори підтягнуті до GND резисторами `R4, R5` (100 кОм) і керуються через резистори `R3, R2` (47 кОм).
  - Сенсорний дріт від внутрішньої мідної фольги на корпусі підключено напряму до `GPIO 1`.

### Поточна розпіновка (Pinout)
- **Живлення +5V / GND:** від перемички `J3` / `U1 Pin 1` -> `5V (VIN)` та `GND` ESP32-S3.
- **Холодний білий (PWM):** `GPIO 4` (LEDC Channel 0, 1000 Hz, 10-bit `0..1023`).
- **Теплий жовтий (PWM):** `GPIO 5` (LEDC Channel 1, 1000 Hz, 10-bit `0..1023`).
- **Сенсорна кнопка (Touch):** `GPIO 1` (`touchSetCycles(0x0800, 0x1000)`, автокалібрування бази при старті з 30 замірів, фільтр з 4 замірів, гістерезис: `TOUCH_DELTA_ON = 3500`, `TOUCH_DELTA_OFF = 2000`).

### Зарезервовані піни під Етап 2 (Stage 2)
- **I2C шина (3.3V):** `GPIO 8` (SDA), `GPIO 9` (SCL).
- **UART під радар (3.3V логіка, 5V живлення):** `GPIO 17` (ESP TX -> Radar RX), `GPIO 18` (ESP RX <- Radar TX), швидкість `256000 baud`.

## 4. План подальшої роботи (Stage 2 — Наступні кроки після паузи)
Потрібно інтегрувати у поточну архітектуру 4 нові апаратні модулі:
1. **BH1750** — датчик інтенсивності освітлення (шина I2C: `GPIO 8` SDA, `GPIO 9` SCL, адреса `0x23`, живлення `3.3V`) для адаптивної підтримки заданого рівня освітленості (люксів) на робочому столі.
2. **SHT31** — датчик температури та вологості (на тій же шині I2C: `GPIO 8` SDA, `GPIO 9` SCL, адреса `0x44`, живлення `3.3V`).
3. **HLK-LD2410** — міліметровий 24 ГГц радар присутності (UART `256000 baud`: `GPIO 17` TX, `GPIO 18` RX, живлення `5V`, логіка `3.3V`) для автоматичного плавного вмикання при появі людини та вимикання за таймером при відсутності.
4. **1.28" круглий TFT дисплей `240×240` на драйвері `GC9A01`** (апаратний SPI2 на вільних пінах ESP32-S3, бібліотека `LovyanGFX` із 8-bit `RGB332` спрайтом на 57.6 КБ SRAM для відображення годинника/температури/вологості/люксів/режиму лампи у фірмовому круглому дизайні).
